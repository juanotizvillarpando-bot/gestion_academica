===================================================================
SISTEMA DE GESTIÓN ACADÉMICA - APLICACIÓN WEB FULL-STACK
===================================================================

Arquitectura moderna Web:
- Backend: ASP.NET Core Web API (.NET 10) con conexión nativa a SQL Server (.\SQLEXPRESS).
- Frontend: Aplicación React 18 + Vite + Tailwind CSS + Lucide Icons.
- Autenticación: Inicio de sesión obligatorio por credenciales y roles.
- Navegación: Barra Uiverse Squircle Dock con SVG clipPath y elevación fluida.

---------------------------------------------------
¿CÓMO INICIAR EL SISTEMA?
---------------------------------------------------
1. Opción 1 (Recomendada):
   Haz doble clic en "iniciar_web.bat" (o "iniciar.bat").
   El servidor arrancará en menos de 1 segundo y abrirá tu navegador en:
   👉 http://localhost:5000

2. Opción 2 (Desde la Terminal):
   Abre PowerShell en esta carpeta y escribe:
   .\iniciar_web.bat

3. Opción 3 (Modo Desarrollo con Recarga en Vivo):
   Haz doble clic en "iniciar_dev.bat".
